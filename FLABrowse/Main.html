This is the home page!


Here's the basics!


the HOME button sends you to this page


The SITES button sends you to a page with a list of sites


The TOOLS button opens a sidebar for tools


What about the 2 input bars?


The first and bigger input bar is for URLs, Enter your URL and press the GO TO button to open the URL you entered


The second and smaller input bar is for CSS files, Enter the location of a CSS file and press GET to attach the CSS file


Extra stuff


You must put HTTP:// or HTTPS:// before any web links or CSS files on the internet


This is a work in progress web browser and will not load anything other than text and sometimes images


If you are viewing through Ruffle flash emulator, Images will not load


If you don't know any css files, typing "Default.css" and clicking GET loads a basic CSS file
